# 人事考課表III デジタル入力

`index.html` 1ファイルだけで動きます（インターネット接続・サーバー不要、データは外部に送信されません）。

## 流れ
1. **スタッフ**：`index.html` を開く（考課期間の入力は不要） →「スタッフ（自己評価）」で入力 →「提出ファイルを作成」→ できた `.json` を担当者に送る（共有フォルダ／メール等）
2. **一次考課者**：「一次考課者」タブ → 提出ファイルをまとめてドロップ → 一人ずつ一次評価・コメントを入力（考課表Ⅱの人は「様式」をⅡに切替。項目は共通で表題のみ変わる）
3. **印刷**：「この人を印刷」または「全員分を印刷」→ A4横で従来様式どおり印刷（二次考課欄は空欄）→ 最終考課者へ

## 注意
- 一次考課の途中経過はブラウザに自動保存されますが、履歴削除で消えます。区切りごとに「全員分を保存」でバックアップしてください。
- 「集計CSV」で全員の点数をExcelで確認できます。
